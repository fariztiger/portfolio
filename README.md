## Edit and publish

1. Change content, project URLs or email links in `index.html`.
2. Commit updates to the `main` branch.
3. GitHub Pages will publish changes automatically if branch deployment is enabled.

The site uses semantic HTML, keyboard focus styling, reduced-motion preferences, responsive layout and decorative SVG icon markup.
