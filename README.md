# Faiz Suhaimi — Personal Portfolio

Responsive single-page freelance portfolio featuring Web3 research, MT4/MT5 trading automation, Python workflows, web projects and software QA.

## Local preview

Open `index.html` in a browser. No build process or dependencies are required.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then click **Save**.
4. When deployment completes, open **https://fariztiger.github.io/portfolio/**.

## Update contact and projects

Edit `index.html` directly. The portfolio currently uses a `mailto:` link for enquiries and points to public project repositories.

All project descriptions are for independent work; no claims of audited or guaranteed profitable systems are made.
